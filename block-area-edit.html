事件

噪域事件模型 · 速查

每个噪域由 7 条事件轨 描述，每条轨是一串「事件」。一个事件 = 一段区间 + 起始值 + 终止值 + 缓动曲线。

{
  "centerX": [ { "startTime":[8,0,1], "endTime":[12,0,1],
                 "start": -675, "end": 675, "easingType": 1 } ],
  "centerY": [...], "width": [...], "height": [...], "rotation": [...],
  "visible": [ { "startTime":[8,0,1], "endTime":[16,0,1], "value": true } ],
  "active":  [ { "startTime":[8,0,1], "endTime":[16,0,1], "value": true } ]
}

求值规则：
· 第一个事件之前 → 取默认值（X=0, Y=0, 宽=1350, 高=900, 旋转=0, 出现=false, 生效=false）
· 事件区间内 → start + (end-start) · f(p)，p 为区间内进度
· 事件结束后到下一个事件开始前 → 保持上一个事件的终值不变
· visible / active 是布尔轨，不使用缓动，值在整个事件区间内有效

时间单位：拍（Beat 三元组 [小节,拍,分母]），随 BPMList 换算。坐标单位：RPE 单位（1350×900，原点居中）。

缓动选择（3 个输入框联动）：数字 id = 写入文件的 easingType（1..29）； 方向 = In / Out / InOut；类型 = Plain / Sine / Quad / Cubic / Quart / Quint / Expo / Circ / Back / Elastic / Bounce。 三者共用 Phira 内部的 TweenId = 类型×3 + 方向，经 RPE 编号表互相换算，选中后下方实时画出该曲线。 方向下拉里标「无 id」的组合在 RPE 缓动编号中不存在（Expo·InOut、Quint·InOut、Plain·In、Plain·Out）。

缓动 1..29（顺序同 Phira 的 RPE 缓动表）：
1 Linear · 2 OutSine · 3 InSine · 4 OutQuad · 5 InQuad · 6 InOutSine · 7 InOutQuad · 8 OutCubic · 9 InCubic · 10 OutQuart · 11 InQuart · 12 InOutCubic · 13 InOutQuart · 14 OutQuint · 15 InQuint · 16 OutExpo · 17 InExpo · 18 OutCirc · 19 InCirc · 20 OutBack · 21 InBack · 22 InOutCirc · 23 InOutBack · 24 OutElastic · 25 InElastic · 26 OutBounce · 27 InBounce · 28 InOutBounce · 29 InOutElastic

操作
· R 在鼠标最近的吸附线建事件头，再按一次建事件尾（列 = 鼠标所在的列）
· 拖动时间轴左侧刻度尺 = 移动播放头（不吸附）
· 滚轮上下滚动时间轴，Ctrl+滚轮缩放
· 点击事件方块 → 右侧编辑；Delete 删除
· 预览画面里拖拽 = 改当前值位置/边长，再点右侧 ⟲ 同步 写入事件
